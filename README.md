# Oluwatimilehin Akingbade — Portfolio

A clean, Android-focused developer portfolio built with Next.js.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Deploy to Vercel

1. Push this folder to a GitHub repository.
2. Go to https://vercel.com/new
3. Import the repository.
4. Click Deploy.
5. Use the resulting Vercel URL as your Portfolio URL.
